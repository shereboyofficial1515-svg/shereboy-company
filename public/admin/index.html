    Project Previews

    Control the “Live Preview” button and check whether each website can be shown inside your site.

    How previews work. Some websites tell browsers not to display them inside other sites (a security setting called X-Frame-Options or frame-ancestors). Visitors then see a polished “Open in new tab” option instead of a broken preview. If a website is yours, you can allow previews by permitting https://shereboytechltd.site in its frame-ancestors setting.
